# Movie Ticket Booking System

A full-stack movie ticket booking system built with PHP and MySQL, featuring customer booking, ticket generation, and an admin panel for managing movies and customer records.

## Features
- Movie ticket booking with customer info
- Ticket receipt generation
- Admin login and dashboard
- Customer search, edit, and delete
- Movie management (add, edit, delete, set pricing)

## Tech Stack
- PHP
- MySQL
- HTML/CSS (frontend)

## What I'd improve
- Add a "delete all" option for clearing customer records after a showing
- Add revenue/sales tracking for the admin panel
- Refine the database structure (some relationships could be cleaner)
- Add input validation and more robust error handling

## Reflection
This was my first full-stack project, and it grew from a simple booking form into a full system with an admin panel and database as I kept adding features. I'm proud of it as a first attempt — it taught me how to structure a multi-table database or how messy things get without planning the schema first.
